# 0080 — Тема результата раскрывается сразу, размытие не обрезано

## Что чинить

Замечания владельца по экрану результата после живого прогона 23.09.2026:

1. **Тема долго раскрывается.** Раскрытая тема сначала пустая, строки появляются через 2–3 с.
   Причина: появление результата («один раз за визит, ≈ 1 с», `site.css`) держится классом
   `is-revealing`, а класс не снимается — `reveal` в `CheckWizard.tsx` считается при отрисовке
   по `seen`-ref, и после появления ничто экран не перерисовывает (DONE не опрашивается,
   раскрытие `<details>` отрисовки не вызывает). Строки материалов проявляются с задержкой
   `760ms + --i × 70ms`, а `--i` — сквозной счётчик строк всех тем (`ResultScreen.tsx`): строки
   четвёртой темы ждут 2,4–2,9 с, пятой — около 3,5 с.
2. **Размытый текст обрезан.** Строка скрытого заголовка (`.site-finding__list li`) режет
   содержимое `overflow: hidden` без полей по вертикали — ореол размытия (≈ 7 px) срезан сверху
   и снизу у каждой строки; раскрытая тема (`.site-theme::details-content`, `overflow: hidden`
   ради анимации высоты) срезает и боковые поля строки, и верх первой строки.

Решений владельца не требуется: это дефекты, поведение задано макетом и комментарием
`site.css`.

## Как

1. **Кто участвует в появлении — отвечает проекция** (`themeRows`, `result-view.ts`): у строки
   темы `openAtLoad` (раскрыта при загрузке — первая) и `revealLines` — порядковые номера строк
   в появлении, с нуля внутри этой темы; у закрытых при загрузке тем `null`. `ResultScreen` берёт
   `open` и `--i` оттуда и помечает участвующие строки `is-staged`; правило анимации в
   `site.css` — только для `.is-staged`. Сквозного счётчика больше нет.
2. **Появление кончается, когда человек сам раскрывает тему.** `ResultScreen` зовёт `onSettle`
   по щелчку заголовка темы; мастер перерисовывается, `reveal` уже `false` — класс снят, ничего
   не проигрывается заново (в том числе при повторном раскрытии первой темы в браузерах, где
   закрытое содержимое `details` — `display: none`).
3. **Размытию — место.** Строка режет только по горизонтали (`overflow-x: clip`), поля строки
   по бокам — одной переменной `--site-blur-bleed` (8 px); `::details-content` раскрытой темы
   получает то же поле по бокам и 4 px сверху отрицательным полем с равным отступом — область
   обрезки шире, а текст не сдвигается ни на пиксель; в закрытой теме высота не меняется.

## Тесты (красные до кода)

`tests/unit/result-themes-open-at-once-and-blur-is-whole.test.ts`:

1. раскрыта при загрузке ровно первая тема;
2. строки первой темы нумеруются с нуля, у остальных тем номеров нет — номер строки не зависит
   от других тем;
3. `site.css`: анимация строк материалов — только у `.is-staged`;
4. `site.css`: строка скрытого заголовка не режет по вертикали (нет `overflow: hidden`);
5. `site.css`: у `::details-content` темы поле по бокам — та же `--site-blur-bleed`, что у строки.

Не держится юнитами: снятие класса по щелчку (`CheckWizard.tsx`, TSX vitest проекта не
собирает) — проверяется в браузере: раскрыть четвёртую тему, закрыть и раскрыть первую.
Вид размытия — снимками до и после на стенде **без ключей провайдеров** (демо-агенты,
вымышленное ФИО, образец `demo:self-check-verdict --sample`): ни одно имя не уходит в поиск.

Мутации: вернуть сквозной счётчик в проекции; вернуть `overflow: hidden` строке.
