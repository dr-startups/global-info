# 0081 — Панель «Это вы?» предлагает только статьи о людях с этим именем

## Что чинить

Живой прогон 23.09.2026: для публичного лица панель предложила, кроме его статьи, страницу
фамилии, статью о народе, область рождения, награду и англоязычную спортивную федерацию —
каждую с кнопкой «Это я». Поиск Википедии полнотекстовый (`list=search`), и
`listNamesakeCandidates` (`providers/wikipedia-provider.ts`) делает карточкой каждый результат:
отбор здесь был отключён намеренно (ENGINEERING §8 «Ворота выбора персоны субъекта»,
тест `persona-panel-shows-namesakes-not-a-choice` держит страницу фамилии первой карточкой).

## Решение владельца (23.09.2026)

«Только статьи-люди»: карточка — статья, в заголовке которой названы фамилия и имя. Полные
тёзки остаются, и выбор между ними по-прежнему делает человек. Прежнее решение §8 меняется
сознательно.

## Как

- В `listNamesakeCandidates` результаты поиска проходят `isMatch(title, terms)` **до** запроса
  лида и межъязыковой ссылки: страница фамилии, область, награда, федерация выпадают и не
  стоят запросов. `isMatch` уже отвечает в провайдере на вопрос «названы ли в заголовке
  фамилия и имя» (путь отчёта), второго сопоставления имён не заводится.
- Страницы неоднозначности («Потанин, Владимир» — фамилия и имя в заголовке есть, а сама
  страница — список тёзок; найдено живой проверкой уже после первого красного лога) снимаются
  по признаку Википедии `pageprops.disambiguation`, одним запросом на раздел; сбой запроса
  ничего не отсеивает.
- Это не отбор «какая статья — наш субъект» (`pickWikipediaCandidate` на пути панели
  по-прежнему не применяется): отвечаем только «человек ли с этим именем», а из тёзок
  выбирает посетитель.
- ENGINEERING §8: абзац о панели переписывается — отбор «статья о человеке с этим именем»
  есть, отбора «какой из тёзок наш» нет.

## Тесты (красные до кода)

`tests/unit/persona-panel-offers-only-people-with-the-name.test.ts` (вымышленный «Петров
Иван Иванович», подменённый `fetch`):

1. страница фамилии, область, награда — не карточки; порядок людей — порядок поиска;
2. английский раздел: федерация отсеяна, статья о человеке осталась;
3. два полных тёзки остаются оба, пометки выбранного нет;
4. лид тянется только статьям о людях.

Правки старых тестов (называются в коммите): `persona-card-lead-comes-from-the-article` —
кандидатов 4, а не 5 («Петровы» выпала), хвост без лида — четвёртый кандидат;
`persona-panel-shows-namesakes-not-a-choice` — фикстура источника без страницы фамилии,
комментарий о ней переписан.

Мутация: убрать фильтр `isMatch` — тесты 1, 2, 4 краснеют.

## Вне рамок

Глубина поиска (`srlimit=5`) не меняется. Статья о тёзке, у которой в заголовке нет имени
(«Усманов (фамилия)» без имени), выпадает — это и есть решение.
