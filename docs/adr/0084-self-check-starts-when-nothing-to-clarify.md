# 0084 — Проверка запускается сама, когда уточнять нечего

## Что меняем

Панель «Это вы?» без единой карточки сейчас показывает экран «Уточнять нечего» — заголовок,
список опрошенных источников и кнопку «Начать проверку». Выбирать на нём нечего, и нажатие —
лишний шаг между формой и проверкой (предложение владельца 24.09.2026). Хуже того, его текст
«Публичных упоминаний с таким именем … не найдено» ложен, когда источник не ответил: живые
прогоны 23 и 24.09 — Википедия `TIMEOUT`.

## Решения владельца (24.09.2026)

1. Карточек нет — проверка запускается сразу, экрана «Уточнять нечего» нет.
2. Так же и тогда, когда карточек нет из-за молчания источника: выбирать всё равно не из чего.

## Как

- **Сервер решает там, где знает факт.** `buildSelfCheckPersona` (`self-check/service.ts`)
  после сборки панели без карточек сам записывает решение `APPROVED_WITHOUT_PERSONA` (тем же
  путём, что решение посетителя) и запускает лёгкий прогон (`startSelfCheckRun`). Браузер
  ничего не решает: закрытая вкладка не останавливает проверку, а второго ответа на вопрос
  «запускать ли» нет.
- **«Выбирать было не из чего» — данные, а не новое слово.** Решение то же, число карточек
  панели — ноль; отчёт уже пишет по этим данным «панель не показала ни одной карточки»
  (`front-matter.ts`). В аудите решения — `automatic: "NO_CANDIDATES"`: записал сервис, а не
  посетитель.
- Панель, собранная до выката и оставшаяся без решения, при следующем обращении проходит тот
  же путь.
- Решение уже записано или прогон уже начат (второй запрос) — не ошибка: запуск идемпотентен
  по условному обновлению записи. Прогон не стартовал по другой причине — запись остаётся
  `PERSONA_DECIDED`, и мастер показывает экран запуска с кнопкой; его текст для этого случая
  без «Совпадение отмечено».
- **Мастер.** Состояние `persona-empty` и экран `PersonaEmptyScreen` удаляются вместе с
  текстами; `PERSONA_PENDING` с пустой панелью — это ещё «ищем», пока свежий статус не скажет
  «идёт проверка». После ответа панели статус перечитывается всегда.
- Текст экрана поиска упоминаний перестаёт обещать выбор, которого может не быть.

## Тесты (красные до кода)

`tests/unit/self-check-starts-when-nothing-to-clarify.test.ts` (фейковая база
`self-check-fakes`, подменённый запуск):

1. пустая панель — решение `APPROVED_WITHOUT_PERSONA`, статус `RUNNING`, прогон запущен один
   раз, аудит решения с `automatic: "NO_CANDIDATES"`;
2. панель с карточкой — решения нет, статус `PERSONA_PENDING`, прогон не запущен;
3. запуск упал — панель отдана, статус `PERSONA_DECIDED`;
4. пустая панель, собранная раньше и без решения, — повторное обращение запускает проверку;
5. мастер: `PERSONA_PENDING` + пустая панель — экран поиска, а не «Уточнять нечего».

Правка старого теста (называется в коммите): `check-wizard-state-is-derived-from-public-status`
— случай «без карточек — «Уточнять нечего»».

Мутации: убрать автозапуск — тесты 1, 4; запускать и при карточках — тест 2.

## Вне рамок

Запуск прогона из админки (оператор решает сам). Качество вердикта — отдельный вопрос
владельцу.
