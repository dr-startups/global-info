# 0085 — User-Agent Википедии называет настоящий контакт

## Что чинить

Запросы к Википедии уходят с `User-Agent` «GlobalInfo-DigitalProfile/1.0 (compliance audit;
contact: admin@example.com)» — контакт-заглушка. Правила Wikimedia (User-Agent policy)
требуют настоящий способ связи; клиентов без него ограничивают сильнее, а ответ 429 наш
`fetchJson` честно выжидает. Это кандидат в причины 20-секундных задержек панели «Это вы?»
(живые прогоны 23 и 24.09.2026) и в любом случае нарушение правил законного API.

Значение по умолчанию при этом живёт в `providers/config.ts`, а не в `config/defaults.ts`,
где правило проекта держит все несекретные значения.

## Решение владельца (24.09.2026)

Контакт — `anton.kovalenko10@mail.ru`.

## Как

- `TEXT_DEFAULTS.DIGITAL_PROFILE_WIKIPEDIA_USER_AGENT` в `config/defaults.ts` — строка с
  контактом владельца; `providers/config.ts` читает её `textSetting` (переменная окружения
  по-прежнему может её заменить).

## Тесты (красные до кода)

`tests/unit/wikipedia-user-agent-names-a-contact.test.ts`:

1. без переменной окружения `User-Agent` называет контакт владельца, заглушки
   `example.com` в нём нет;
2. переменная окружения по-прежнему заменяет значение.

Мутация: вернуть заглушку — тест 1.

## Вне рамок

Причина задержки панели — журнал `wikipedia_request` следующего живого прогона.
